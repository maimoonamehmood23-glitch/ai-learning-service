# AI Learning & Training Services Website

## 1. Project Purpose

The purpose of this website is to provide simple and accessible AI learning and training services for students, teachers, and beginners.

The website should help users understand available AI training programs and easily contact the training service.

## 2. Target Users

The main target users are:

- Students
- Teachers
- Beginners learning Artificial Intelligence
- People interested in AI tools and technology

## 3. Website Goals

The website should:

- Introduce the AI learning services
- Display available training programs
- Explain the benefits of AI learning
- Help users contact the training team
- Provide a simple and professional user experience

## 4. Main Pages / Sections

The website should contain:

1. Home
2. About
3. Services
4. Training Programs
5. Contact

## 5. Core Features

The website should include:

- Responsive navigation bar
- Hero section
- Call-to-action button
- Services cards
- Training program cards
- About section
- Contact form
- Footer
- Smooth scrolling
- Mobile responsive design

## 6. User Flow

The user flow should be:

1. User opens the website.
2. User sees the main hero section.
3. User learns about the AI training service.
4. User explores available services.
5. User views training programs.
6. User can contact the training team.
7. User can click the Get Started button.

## 7. Design Requirements

The website should have:

- Modern and clean design
- Professional appearance
- Simple navigation
- Good spacing
- Easy-to-read typography
- Attractive service cards
- Responsive layout
- Mobile-friendly design
- Professional AI/technology theme

## 8. Technical Requirements

Use:

- HTML5
- CSS3
- JavaScript

Do not use unnecessary complex frameworks.

The website should work in a modern web browser.
